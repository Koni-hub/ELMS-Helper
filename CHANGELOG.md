# Changelog

## [0.1.0] - 2026-11-06

Initial public release.

- Scan assignment rows from enrolled STI ELMS courses.
- Skip submitted, past-due, divider, Teacher Evaluation, and Student Grade
  Monitoring entries.
- Read assignment instructions and PDF attachments, then prepare answer PDFs
  with requested diagrams and wireframes as inline SVG graphics.
- Save output by course and assignment, and stage answers when ELMS exposes a
  suitable answer field or upload control.
- Never click Submit; the user reviews and submits manually.
- Include first-run Windows setup, clone instructions, and the MIT license.
